# Reporting security issues

cdxgen security reports follow the main project policy in the [cdxgen repository](https://github.com/cdxgen/cdxgen/blob/master/SECURITY.md).

To report a security issue, email [cloud@appthreat.com](mailto:cloud@appthreat.com) with the word **"SECURITY"** in the subject line, or use private reporting at [github.com/cdxgen/cdxgen/security/advisories/new](https://github.com/cdxgen/cdxgen/security/advisories/new). Please do not open public issues for suspected vulnerabilities.

The project leaders listed on the project webpage can also be contacted for anything that is not a cdxgen code or release issue.
